# GRBW Hub

I want to make a website for a community known as GRBW . i want it to look like rbw.gg website but with my own symbol as shown in the 1st picture. i want it to have 5 catagories named Home [for main page], Leaderboard [connected to discord bot from where websites take the leaderboard and generates a leaderboard image], Perks [for adding custom purchase perks which the admin of the web can add using a '+' sign which is only visible to admins], Store [for adding custom purchasing exclusive items which the admin of the web can add using a '+' sign which is only visible to admins], Links [which will have all the social media links of the community which could be added by '+' sign which is only visible to admins]. And i want that admins could add a video of yt in the home catagory wih a big '+' sign only visible to admins.
